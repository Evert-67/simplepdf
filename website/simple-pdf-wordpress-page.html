Turn your WordPress content into a PDF with a layout you control. Simple PDF adds a button to your pages and posts, so visitors can open or download a document using your own HTML/CSS template.

Download Simple PDF 4.4.2

Free to download · WordPress 6.3+ · PHP 8.0+ · Requires mbstring and gd

A PDF that fits your content

Reusable layouts. Build templates with HTML, mPDF-compatible CSS and content shortcodes. Duplicate a design or transfer templates between sites with JSON import and export.

Flexible buttons. Choose automatic placement, a Gutenberg block or a shortcode. Use a fixed template or offer visitors a template selector.

Your preferred output. Open PDFs in a new tab or download them. Adjust the button colours, icon and size, and choose a filename pattern.

Get started

1. Install the plugin. Download the installation ZIP above. Upload it through Plugins → Add New → Upload Plugin, then activate it. Upload the ZIP without extracting it.

2. Create your first template. Open Simple PDF Print and add a template. Use the minimal template below as a starting point.

3. Save and preview. Select preview content and click Save & Test PDF. The preview opens in a new tab while the editor remains open.

4. Add a button. Publish your template, then add a PDF button block or one of the shortcodes below to a page.

Choose the installation ZIP. GitHub’s Code → Download ZIP and Source code archives are development files. The installation ZIP includes mPDF and its fonts.

Button examples

Replace 123 with the ID of your published template. The examples below are displayed as text; they are not live PDF buttons.

A simple button

[print_pdf_button template="123" label="Create PDF"]

Download a PDF with an icon

[print_pdf_button template="123" label="Download PDF" icon="download" output="download" size="large"]

Let visitors choose a template

[print_pdf_button template="0" label="Create PDF" align="center"]

Control width and alignment

[print_pdf_button template="123" label="Open PDF" output="inline" align="right" width="250px" class="my-pdf-button"]

Prefer the block editor? Add the PDF button block and choose the options in its settings. Set the page’s PDF button placement to None when adding a manual button to avoid duplicates.

Your first PDF template

Paste this into the plugin’s template editor. The content shortcodes insert the selected page’s title, site name, date and content.

<style>
body { font-family: sans-serif; color: #243b40; }
h1 { color: #225f6a; }
</style>
<h1>[post_title]</h1>
<p>[site_name] · [post_date]</p>
[post_content]

Other useful template shortcodes include [site_logo width="100"], [post_author], [post_excerpt] and [pagebreak]. Set a logo in your theme before using the logo shortcode.

PDF layout uses mPDF-compatible HTML and CSS. A website framework can style the button, but not every modern browser CSS feature is supported inside a PDF.

Useful settings

Filename patterns: use {site}-{title}-{date}. Available tokens are {title}, {id}, {date}, {site} and {template}. The .pdf extension is added automatically.

Default templates: automatic buttons use an explicit page setting first, then the post-type default, then the global default. Manual buttons retain their own template selection.

Save & Test: always requests an inline preview in a new tab, even when visitor buttons are configured to download. Browser preferences can affect how the PDF opens.

Frequently asked questions

Where are my templates stored?
In your own WordPress database. Installing an update preserves them. Your templates are not included when someone else downloads the plugin.

Which templates can visitors use?
Published templates can appear in the selector. Keep unfinished or internal-only designs as drafts. PDF generation also checks access to the source content. Membership plugins may need an additional integration.

Does template export include images?
No. JSON contains the template code, descriptions and categories. Images and fonts remain linked; transfer those files separately when moving a site.

Where is the full manual?
Open Simple PDF Print → Read Me and Shortcode Reference in WordPress for detailed instructions and troubleshooting.
